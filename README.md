# DevSecOps Pipeline Starter Kit

Most DevSecOps pipelines fail for one simple reason:

They dump scanner output on developers without context.

This project demonstrates a developer-friendly security pipeline that runs common security checks, summarizes findings, 
applies policy-based gates, and generates a clean report that engineering teams can actually use.

## What this project demonstrates

- Secret scanning
- Dependency scanning
- Container scanning
- Static analysis
- Policy-based pass/fail decisions
- Markdown security report generation
- Exception handling concept
- Jenkins and GitHub Actions examples
